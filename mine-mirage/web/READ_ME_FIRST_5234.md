# MINE//MIRAGE 3D — BUILD 5234 · Буровзрывные работы

## Как запустить

1. Распакуйте архив целиком. **Не открывайте `index.html` напрямую**: браузеру нужен локальный HTTP-сервер для ES-модулей и GLB.
2. Windows: запустите `START_HERE_WINDOWS.bat`. Если Python не установлен, установите Python 3 и убедитесь, что команда `py -3` работает. Можно вручную в папке проекта выполнить `py -3 -m http.server 5233`.
3. Откройте `http://127.0.0.1:5233/` в Chrome/Edge.
4. Ubuntu: `bash START_HERE_UBUNTU.sh`, затем тот же адрес.

## Как пользоваться БВР

- В левом меню выберите **«Буровзрывные работы»**. Также есть кнопки **«Буровой участок · MWD»** на 3D-карте и **«БВР»** в углу карты.
- Нажмите **«Запустить учебный цикл»**. Видны 20 условных скважин (4×5), буровой станок, стадии подготовки, эвакуации, защитного отсчёта, проветривания и осмотра.
- По мере бурения раскрываются **MWD-индексы** (показатели крепости породы, проходки и момента), а ячейки меняют цвет в панели и 3D-сцене.
- После завершения безопасных стадий обновляются **доля мелкой/крупной фракции**, скорость погрузки материала с северного забоя и скорость его переработки дробилкой. Все эффекты проходят через основной симулятор, а не являются декоративной анимацией.
- Если техника не вышла из опасной зоны, выполнение блокируется до подтверждения периметра. Отменить можно до выполнения условного взрыва.
- Есть две карты: **Сарыарка** и **Алтай**. Смена карты/сброс заново создают модель и скважины.

## Важно

Это **учебный цифровой двойник**, не проект буровзрывных работ. Показатели MWD, фрагментации и производительности синтетические. Сетка графическая: в модели отсутствуют физические глубины, расстояния, заряды и схемы инициирования, поэтому её нельзя использовать для настоящих взрывов.
